# 刘希｜增长分析与实验决策作品集——中文使用指南

这是一套可直接在线操作的数据分析作品。访问者无需安装软件、登录 GitHub 或了解代码，即可查看两个用户增长案例及其完整分析链路。

## 一、最快使用方式

直接打开：

**[https://liu-xi71.github.io/liu-xi-growth-analytics-portfolio/](https://liu-xi71.github.io/liu-xi-growth-analytics-portfolio/)**

建议使用电脑浏览器，以获得完整图表与决策卡布局。手机也可以访问，页面会自动适配。

## 二、建议浏览顺序

### 1. 决策总览

首页集中展示当前业务判断与行动优先级。每张决策卡包含：

- 业务异常；
- 影响范围；
- 反向证据；
- 证据等级；
- 剩余不确定性；
- 建议行动。

首页底部展示两个案例共用的分析框架：

```text
看板发现异常
→ 指标合同统一口径
→ 分层 / 漏斗定位
→ 反向证据收敛范围
→ A/B 实验验证策略
→ 价值护栏与持续监测
```

### 2. 智能分析

选择左侧业务问题，再点击“展开下一步”。页面会依次展示：

1. 问题界定；
2. 指标合同；
3. 确定性计算；
4. 反向证据；
5. 可检验假设；
6. 实验或价值评估；
7. 结论边界。

所有业务数值均由固定规则计算。智能解释只组织已有证据，不生成业务数值。

### 3. 自动周报

选择“老带新增长”或“新用户留存”，再切换案例阶段，可查看结论如何随证据演进。周报区分三类来源：

- 系统计算：指标、变化和统计结果；
- 智能解释：基于既有证据形成的结构化摘要；
- 人工确认：业务判断、行动建议和适用边界。

点击“下载 Markdown”可保存当前周报示例。页面中的监控周为案例阶段回放，不代表公司真实自然周数据。

### 4. 案例链路

选择一个案例并点击“推进下一步”，可按顺序查看从异常识别到策略评估的完整过程。

两个案例采用同一套分析原则：建立指标层级、使用反向证据收敛问题空间、由观察性关联形成可检验假设，并通过随机实验与价值护栏支持决策。

### 5. 实验决策

该页面可以实际修改参数并重新计算：

- 历史基线；
- MDE（最小可检测提升）；
- 显著性水平；
- 统计功效；
- 每日流量；
- 对照组与实验组样本量；
- 两组转化率；
- 价值护栏状态。

页面同时演示：

- 最小样本量与整周实验周期；
- 基于用户 ID 的稳定 Hash 分流；
- A/A、埋点与人群均衡检查；
- SRM、统计显著性与业务显著性；
- 价值护栏与综合决策。

A/A、实际分组人数、SRM 和分层均衡的真实项目结果未披露，因此页面不会默认标记为已通过。

### 6. 指标治理

“指标合同”页签说明每个指标的：

- 分子和分母；
- 观察窗口；
- 统计粒度；
- 决策用途；
- 适用结论；
- 使用限制。

“证据账本”页签记录事实、计算方法、证据来源与结论边界。可以按案例、证据类型或关键词筛选。

## 三、两个案例的核心信息

### 老带新获客增长

- 核心业务指标：拉新用户数；
- 关键机制指标：邀请点击率；
- 主要诊断：复杂升级后邀请点击率由约 21% 降至 17%；
- 反向证据：分享成功率约 95%，降低分享完成环节作为主要断点的优先级；
- 策略假设：页面信息复杂、邀请入口后置可能提高动作发现成本；
- 实验：新版简化页面、邀请按钮前置，对照组使用旧版；
- 周期与样本：两周、总样本约 700 万；
- 结果：实验组邀请点击率为 23.5%，较对照组提升 6.5 个百分点，`p < 0.05`；
- 价值护栏：首月价值/激励成本倍数为 2.18，高于同口径外投的 1.90；
- 决策：支持在首屏简化版本上持续迭代并滚动监测。

### 新用户留存

- 核心业务指标：次 7 日内留存率，即新增后 D1–D7 至少回访一次；
- 异常：留存率由 48% 降至 41%；
- 分层发现：平板留存率约比手机低 10 个百分点，且平板新增占比方向上升；
- 量化边界：缺少分期设备占比，无法准确量化真实结构贡献；
- 反向证据：下载至关注的核心路径转化率未观察到同步下降，降低普遍路径阻塞作为主要解释的优先级；
- 标杆分析：标杆用户关注渗透率约为非标杆用户的 2.5 倍，该结果仅为相关性线索；
- 实验：退出页增加主页浏览与关注引导，对照组不增加引导；
- 周期与样本：两周、总样本约 30 万；
- 结果：次 7 日内留存率显著提升，`p < 0.05`；
- 披露边界：组间绝对留存率未公开，因此不报告绝对效果量。

## 四、数据边界

项目同时使用两类数据，并在页面中明确区分：

1. 去标识化经历事实：只保留已确认的相对变化、实验方向、周期、总样本与显著性结论；
2. 固定规则演示数据：用于支撑图表、数据库查询、结构分解与交互计算，不代表任何公司的生产数据。

本项目不包含雇主内部表名、内部 SQL、生产代码、用户信息、系统凭证或未披露的绝对经营规模。

## 五、本地运行（可选）

在线页面已能展示全部核心能力，本地运行不是查看作品的必要条件。

如需查看完整前后端与数据库链路，先安装 Docker Desktop，然后在项目目录运行：

```bash
docker compose up --build
```

启动完成后打开：

- 可视化页面：`http://localhost:8501`
- API 文档：`http://localhost:8000/docs`

停止服务：

```bash
docker compose down
```

## 六、常见问题

### 为什么页面中部分数字没有给出？

因为原始项目没有公开对应输入。缺少分期设备占比时不能准确量化结构贡献；缺少实验组和对照组的绝对留存率时不能报告绝对效果量。

### 次 7 日内留存率是否等于第 7 日留存率？

不等于。这里的定义是新增后第 1 至第 7 天内至少回访一次。

### 2.18 是否代表完整 ROI？

不代表。这里使用“首月价值/激励成本倍数”，仅比较首月估算价值与归因范围内的邀请激励成本，不等同于完整生命周期价值、完整获客成本或净收益率。

### 为什么关注渗透率 2.5 倍不能直接证明因果？

标杆用户与非标杆用户可能存在先验意愿和行为暴露差异。该结果用于形成产品假设，策略效果由后续随机实验评估。
