# 刘希｜增长与实验：中文使用指南

## 1. 最快打开方式

直接打开 [增长与实验](https://liu-xi71.github.io/liu-xi-growth-analytics-portfolio/)。不需要登录 GitHub、安装软件或配置密钥。

手机通过左上角菜单打开导航；电脑直接使用侧栏。

## 2. 三分钟浏览

| 时间 | 操作 | 看什么 |
|---|---|---|
| 第一分钟 | 查看“业务总览” | 两段实习各解决什么问题，指标与方法如何对应 |
| 第二分钟 | 打开“老带新案例”和“新用户留存案例” | 业务目标、指标体系、诊断、实验与决策五个环节 |
| 第三分钟 | 打开“指标与实验方法” | 指标口径、七步实验流程与结论条件 |

案例页顶部的五个章节按钮可直接定位内容。点击“下载案例摘要”，可保存当前案例的 Markdown 文本；使用记事本或支持 Markdown 的软件即可打开。

## 3. 两段案例分别怎么读

### 老带新

先看邀请点击监控如何从约 21% 降至 17%，再看产品与用研反馈如何形成页面简化策略。实验图单独展示对照组 17% 与实验组 23.5%，不能把两种比较当作同一组实验。

最后查看首月价值/激励成本 2.18 与同口径外投 1.90 的比较。这不是完整生命周期价值、净利润率或营销增量 ROI。

### 新用户留存

先看次 7 日内留存 48% → 41% 的监控变化，再依次阅读用户结构、产品路径和标杆行为分析。重点是“总体变化不等于所有用户组都变差”，以及“标杆行为差异需要实验验证”。

留存实验只展示已公开的两周、约 30 万总样本与 p < 0.05；不将 48% 和 41% 用作实验组间对照。

## 4. 如何使用辅助工具

点击侧栏“分析工具与案例资料”展开：

- **分析链路**：选择业务问题，点击“展开下一步”，逐段查看计算和依据。
- **案例周报**：选择案例与阶段，点击“下载 Markdown”保存报告示例。阶段不是公司真实自然周记录。
- **分步回放**：选择案例，点击“推进下一步”。
- **实验试算**：修改基线、MDE、统计功效或样本数据，查看结果变化。试算组内人数是演示输入，不是项目真实分流人数。
- **指标口径与证据**：搜索指标名称，展开分子、分母、窗口和用途；切换证据页签查看出处。

实验参数要求：样本量为正整数，转化率为 0%–100%，基线加 MDE 小于 100%，每日可用流量为正整数。无效输入会显示修正说明，不生成可推进结论。

## 5. 另外两项作品在哪里

点击侧栏“数据分析作品集”，进入统一入口：

1. 增长与实验：实习案例与方法。
2. CSV分析工作台：导入新 CSV、复算分析并导出报告。
3. 复购运营台：客户分群、候选名单与效果验证。

三项职责不同。本项目不需要再次上传 CSV 才能浏览案例。

## 6. 压缩包与本地运行

完整解压后，优先使用统一入口中的在线链接。该项目压缩包包含源码，不能直接双击 `web/index.html` 运行 React 应用。

如需运行前端、后端与数据库，安装并启动 Docker Desktop，在项目目录执行：

```bash
docker compose up --build
```

打开 `http://localhost:8501`。后端接口说明位于 `http://localhost:8000/docs`。首次运行需要联网下载依赖并生成演示数据。

停止服务：

```bash
docker compose down
```

## 7. 常见问题

### 页面提示“案例数据加载失败”

在线浏览：检查网络后点击“重新加载”。本地运行：确认服务已启动，页面与 `data/growth-analytics.json` 均能访问；不要用文件双击方式打开源码。

### 为什么留存没有实验效果量柱状图

原始项目未公开组间绝对留存率。监控前后变化不能代替实验组间差异，因此页面仅呈现已公开的显著性方向与样本、周期。

### 为什么首次打开实验试算，检查项没有全部通过

A/A、SRM 与人群均衡的真实结果未披露。检查按钮用于当前试算的条件演示，不会把未录入信息当作历史通过记录。

### 页面出现“—”是什么意思

表示当前数据包未提供该数值，不代表零。数据恢复完整后重新加载。

### 这里是否包含公司内部数据

不包含。关键变化来自去标识化经历复盘，行级数据和结构分解示例为计算演示；详细说明见 [数据说明](docs/data-card.md)。
