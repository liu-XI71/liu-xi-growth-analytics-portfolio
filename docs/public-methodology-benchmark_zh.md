# 智能分析产品方法对标

## 对标目的

本项目参考公开数据分析与商业智能产品的成熟设计原则，重点吸收可追溯分析、指标语义治理、自动化报告和自助探索能力。对标仅用于产品方法设计，不复制第三方实现，也不以项目热度替代业务价值判断。

## 公开产品与方法启发

| 公开项目或产品 | 可借鉴能力 | 本项目落地 |
|---|---|---|
| Evidence | SQL 与报告结合、分析结果可复核 | 周报结论绑定指标与证据来源 |
| Metabase | 面向业务人员的低门槛探索 | 六个结构化页面与可操作参数 |
| Superset | 指标、筛选与可视化组合 | 增长指标体系、案例筛选与交互图表 |
| dbt Semantic Layer | 统一指标定义与语义口径 | 指标合同管理分子、分母、窗口、粒度和决策用途 |
| Great Expectations | 数据质量规则化 | 对输入完整性、分流质量和高风险结论进行规则约束 |
| GrowthBook | 实验设计、分析与决策 | 最小样本量、稳定分流、SRM、效果量、MDE 与价值护栏 |

## 核心设计原则

1. 业务问题优先于技术功能展示；
2. 指标定义、计算结果、证据来源和适用边界同步呈现；
3. 自动化输出必须保留可复核的计算与人工决策责任；
4. 观察性分析用于形成假设，随机实验用于识别策略效果；
5. 关键输入缺失时明确数据缺口，不输出无依据的量化结论；
6. 公开演示默认不依赖外部模型、密钥或雇主系统。

## 能力范围

当前版本聚焦用户增长诊断、实验评估、指标治理与自动化决策报告。未纳入以下能力：

- 通用对话入口；
- 未经验证的自然语言 SQL；
- 未经回测的预测模型；
- 依赖外部模型或密钥的公开演示能力。

这些范围约束使在线作品能够稳定运行，并确保业务结论始终可追溯至确定性计算与已声明证据。
