# 指标合同与字典

指标合同不仅用于展示定义，也是分析引擎和叙事层的共同约束。

## 通用字段

| 字段 | 说明 |
|---|---|
| `metric_id` | 稳定且唯一的指标编号 |
| `name` | 面向业务的中文名称 |
| `role` | 最终结果、机制、诊断、质量护栏或价值护栏 |
| `numerator` | 分子及去重方式 |
| `denominator` | 分母及纳入范围 |
| `window` | 观察时间窗口 |
| `grain` | 用户、日、实验或版本粒度 |
| `decision_use` | 该指标影响什么业务决策 |
| `allowed_claims` | 能支持的结论 |
| `forbidden_claims` | 不能支持的结论 |
| `source_type` | 项目事实、演示数据、程序复算或方法论 |

## 老带新指标

### 老带新拉新用户数

- 角色：最终业务结果；
- 分子：通过合格邀请链路完成新用户定义的人数；
- 粒度：用户、日；
- 用途：判断活动是否扩大有效新增；
- 禁止：不能用邀请点击人数直接替代。

### 邀请点击率

- 角色：核心机制；
- 分子：点击邀请按钮的去重老用户数；
- 分母：进入活动页面的去重老用户数；
- 用途：判断页面是否推动邀请动作；
- 允许：定位邀请动作前后的转化变化；
- 禁止：不能单独代表最终拉新用户数。

### 分享成功率

- 角色：诊断；
- 分子：成功完成分享的邀请用户数；
- 分母：发起分享的邀请用户数；
- 用途：判断点击邀请后的分享链路是否同步异常；
- 允许：作为负证据降低某一排查方向优先级；
- 禁止：95% 不等于分享链路绝对没有问题。

### 裂变率

- 角色：链路效率；
- 具体分子分母必须随页面展示，不能只写一个数；
- 禁止：不得与邀请点击率、新用户激活率混用。

### 首月价值/激励成本倍数

- 角色：价值护栏；
- 分子：归因新用户首月估算价值；
- 分母：相同归因范围的激励成本；
- 窗口：新用户首月；
- 允许：在相同窗口、成本和归因规则下比较渠道效率；
- 禁止：不能称为完整生命周期 ROI、LTV/CAC 或净利润率。

## 新用户留存指标

### 次 7 日内留存率

- 角色：核心结果；
- 分子：新增后第 1—7 天内至少再次访问一次的新用户数；
- 分母：完整经历 D1–D7 观察窗口的新增用户数；
- 粒度：新增 cohort；
- 允许：衡量一个完整周内是否发生早期回访；
- 禁止：不得称为“第 7 日当天留存率”。

### 新用户路径转化率

- 角色：诊断；
- 分子：到达下一环节的去重用户数；
- 分母：进入上一环节的去重用户数；
- 用途：识别基础路径阻塞；
- 禁止：核心路径转化率未同步下降不能证明所有产品体验均无问题。

### 功能渗透率

- 角色：相关性探索；
- 分子：使用某功能的目标人群用户数；
- 分母：目标人群用户总数；
- 用途：比较标杆与非标杆行为差异；
- 禁止：渗透率差异不能直接证明功能使用导致留存。

### 设备结构贡献

- 角色：归因；
- 输入：设备占比变化、设备分层留存差异；
- 用途：量化总体变化中与人群结构变化对应的算术分量；
- 禁止：没有占比变化时不能计算精确贡献。

## 实验指标

### 绝对效果

```text
实验组指标 - 对照组指标
```

转化率场景以百分点表示。

### 相对效果

```text
(实验组指标 - 对照组指标) / 对照组指标
```

以百分比表示，不能与百分点互换。

### 护栏指标

用于捕捉策略对用户质量、价值、体验或系统稳定性的负面影响。核心指标显著但护栏不可接受时，不建议推广。
