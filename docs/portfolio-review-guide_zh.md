# 刘希增长分析作品浏览说明

## 作品定位

本作品通过老带新获客与新用户留存两个增长场景，展示刘希对指标体系、业务诊断、A/B 实验、价值评估与决策治理的完整理解。重点不在技术组件数量，而在能否将业务问题转化为可复核、可执行、可持续监测的分析闭环。

## 三分钟浏览路径

### 第一分钟：决策总览

打开首页，重点查看：

- 两类业务异常如何被转化为决策卡；
- 每项判断是否同时呈现反向证据和剩余不确定性；
- 最终业务指标、机制指标与价值护栏是否分层管理；
- 行动建议是否与证据强度一致。

### 第二分钟：两个案例链路

进入“案例链路”，依次查看：

- 老带新案例如何从邀请点击率下降定位到页面信息复杂度与入口可发现性假设；
- 新用户留存案例如何通过用户分层、路径漏斗和标杆用户分析形成候选策略；
- 为什么高位分享成功率和未同步下降的核心路径转化率属于反向证据；
- 为什么观察性关联需要进一步通过随机实验识别策略效果。

### 第三分钟：实验决策与指标治理

进入“实验决策”，修改基线、MDE、统计功效或两组转化率，观察最小样本量、实验周期、SRM、效果量和综合决策如何变化。

随后进入“指标治理”，展开任一指标合同，查看分子、分母、观察窗口、统计粒度、决策用途、适用结论与使用限制。

## 核心能力框架

```text
业务目标与指标体系
→ 异常监测与问题定义
→ 分层 / 漏斗 / 结构分解
→ 反向证据与剩余不确定性
→ 观察性线索与可检验假设
→ A/B 实验与因果识别
→ 统计显著性 + 业务显著性 + 价值护栏
→ 决策、自动周报与持续监测
```

## 两个案例的关键证据

| 主题 | 已确认事实 | 适用边界 |
|---|---|---|
| 老带新机制断点 | 复杂升级后邀请点击率由约 21% 降至 17% | 支持定位关键动作，不等同于最终拉新结果 |
| 分享环节 | 分享成功率约 95% | 降低分享完成环节作为主要断点的优先级，不排除其他问题 |
| 页面简化实验 | 对照组 17%，实验组 23.5%，提升 6.5 个百分点，`p < 0.05`；两周、总样本约 700 万 | 实验识别完整改版策略；实际组内人数、A/A、SRM 和分层均衡结果未披露 |
| 价值评估 | 首月价值/激励成本倍数为 2.18，高于同口径外投的 1.90 | 仅用于首月同窗口、同成本范围比较，不代表完整 ROI、LTV、CAC 或利润 |
| 留存异常 | 次 7 日内留存率由 48% 降至 41% | 指 D1–D7 至少回访一次，不等于精确 D7 留存 |
| 设备结构 | 平板留存约比手机低 10 个百分点，平板新增占比方向上升 | 缺少分期设备占比，无法准确量化真实结构贡献 |
| 核心路径 | 主要路径转化率未观察到同步下降 | 降低普遍路径阻塞作为主要解释的优先级，不作绝对排除 |
| 标杆行为 | 标杆用户关注渗透约为非标杆用户的 2.5 倍 | 仅为相关性线索，用于形成候选策略 |
| 留存实验 | 两周、总样本约 30 万，次 7 日内留存率显著提升，`p < 0.05` | 组间绝对留存率未披露，因此不报告绝对效果量 |

## 作品可体现的差异化价值

1. **以业务结果为起点**：先明确最终业务指标，再选择与策略作用路径最接近的机制指标。
2. **主动使用反向证据**：不仅寻找支持性证据，也记录哪些方向的优先级被降低。
3. **区分相关与因果**：标杆分析用于形成假设，随机实验用于评估完整策略效果。
4. **将显著性转化为决策条件**：同时考虑 MDE、实验可信度、业务效果与价值护栏。
5. **保持结论强度与证据一致**：输入缺失时明确数据缺口，不进行无依据量化。
6. **沉淀可复用机制**：将一次性分析转化为指标合同、证据账本、实验模板和自动周报。

## 数据与归属边界

项目变化来自去标识化经历复盘；行级明细与部分结构占比由固定规则生成，仅用于计算和交互演示。作品不包含雇主生产数据、内部表名、生产代码、用户信息或系统凭证，也不代表字节跳动、小红书或其他公司的官方系统或业务结论。
