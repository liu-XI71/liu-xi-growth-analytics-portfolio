# 刘希｜增长与实验：三分钟浏览指南

## 第一分钟：了解业务目标

打开“业务总览”，区分两个问题：

- 老带新：外部拉新供给承压时，如何改善邀请链路并判断投入价值。
- 新用户留存：付费渠道带来的用户回访下降时，如何诊断并寻找可干预策略。

本人在 mentor 带领下参与分析与实验评估；作品用于呈现业务判断与方法沉淀，不是实习期间上线的企业系统。

## 第二分钟：比较两条分析链路

“老带新案例”和“新用户留存案例”均按五步展开：

业务目标 → 指标体系 → 诊断与策略 → 实验评估 → 决策与沉淀。

| 判断环节 | 老带新 | 新用户留存 |
|---|---|---|
| 监控发现 | 邀请点击约 21% → 17% | 次 7 日内留存 48% → 41% |
| 问题收敛 | 分享成功率约 95%，优先查看邀请动作 | 设备结构压力；路径未同步恶化 |
| 策略线索 | 页面复杂、按钮后置的产品反馈 | 标杆用户关注渗透约为非标杆 2.5 倍 |
| 实验评估 | 页面简化；17% 与 23.5%；两周、约 700 万 | 退出页主页与关注引导；两周、约 30 万；显著提升 |
| 业务决策 | 首月价值/激励成本 2.18，对比同口径 1.90 | 支持产品引导迭代，投放结构建议独立推进 |

## 第三分钟：查看方法与工具

进入“指标与实验方法”，查看指标六要素和七步实验 SOP。辅助入口位于侧栏“分析工具与案例资料”：

- 修改实验参数，观察样本量与决策条件。
- 展开指标口径，检查分子、分母、粒度与窗口。
- 下载案例摘要或案例周报。

## 建议重点关注的能力

1. 最终结果与机制指标分层，不用局部动作替代业务目标。
2. 结构、路径与行为分析分别回答不同问题。
3. 监控对比、相关性线索和随机实验采用不同结论强度。
4. 实验结果与投入价值共同支持下一步行动。
5. 将一次分析沉淀为清晰口径、可操作试算和可下载成果。
