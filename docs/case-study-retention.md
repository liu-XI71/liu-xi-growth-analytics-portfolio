# 案例二：新用户次 7 日内留存

## 业务背景

监控看板发现投放带来的新增用户次 7 日内留存率由 48% 下降到 41%。新增用户早期流失会同时影响增长质量和投放效率，因此需要定位下滑来源并寻找可验证的产品策略。

本人在导师指导下参与用户分层、路径漏斗、标杆用户分析和产品实验评估。

## 为什么使用次 7 日内留存

定义：

> 某日新增用户在首次进入后的第 1—7 天内至少再次访问一次的比例。

该观察窗口覆盖一个完整星期，能够降低用户首次进入日期和周末差异造成的干扰。它不是“第 7 日当天是否回访”，页面和文档不得混用。

## 第一步：用户结构拆解

按以下维度拆解：

- 获客渠道；
- 设备类型；
- 设备品牌；
- 操作系统；
- 年龄和性别；
- 城市等级；
- 地域。

观察到平板用户次 7 日内留存率较手机低约 10 个百分点，同时平板新增占比上升。由此可以判断设备结构形成了下行压力，并向投放侧提出在价值效率可接受的前提下提高手机流量占比的建议；该建议短期未落地。

但仅知道 10pp 的分层差异，不能判断结构解释了全部 7pp 下滑。精确贡献需要平板占比的前后变化：

```text
结构贡献 ≈ 平板新增占比变化 × 平板与手机留存差
```

本项目如果使用演示占比计算，会明确标注为 synthetic 示例，不把它当作实习项目真实占比。

## 第二步：产品路径负证据

为了判断新用户是否因产品上手路径受阻而流失，拆解核心路径：

```text
下载
→ 注册登录
→ 到达首页
→ 浏览点击
→ 浏览作品
→ 点赞 / 收藏 / 评论
→ 浏览博主主页与关注
```

各环节转化率没有出现与留存下滑同步的明显变化，因此当前证据不支持“基础产品路径出现普遍阻塞”是主要解释。

这是一条负证据，只能降低该方向的优先级，不能证明产品完全没有体验问题，也不能排除局部人群、内容匹配和其他路径。

## 第三步：标杆用户分析

按照新用户首月活跃天数和单日使用时长进行二维分层，将高频高时用户定义为标杆用户。项目事实只保留该分层原则，不披露具体阈值；运行演示则使用模拟数据分位数生成可复现分层，不把演示阈值当作实习项目事实。

比较标杆和非标杆用户在以下功能上的渗透率：

- 内容浏览；
- 直播；
- 点赞；
- 收藏；
- 评论；
- 浏览博主主页；
- 关注。

主页浏览与关注的渗透差异最明显，标杆用户约为非标杆用户的 2.5 倍。

证据可支持的结论：

> 高留存活跃与主页/关注行为存在相关性，可以形成产品引导假设。

证据不可支持的结论：

> 关注行为已经被证明会导致留存提升。

高活跃用户可能具有更高的先验关注意愿与更多行为暴露机会，因此标杆分析只负责筛选候选策略方向。

## 第四步：随机实验验证

实验策略：

- 实验组：用户退出内容浏览时，展示进入博主主页并关注的引导；
- 对照组：不增加该引导；
- 周期：两周；
- 总样本：约 30 万；
- 核心指标：次 7 日内留存率；
- 结果：实验组显著提升，`p<0.05`。

项目复盘未披露实验组和对照组的绝对留存率，因此现有证据不足以报告：

- 绝对提升多少个百分点；
- 相对提升百分比；
- 置信区间；
- 是否达到预设 MDE。

能支持的结论是：

> 随机实验支持完整的“退出页提示＋主页入口＋关注引导”策略提升次 7 日内留存率，`p<0.05`；在未披露绝对效果量的边界下，该结果支持当时继续推进并持续优化。

不能支持的结论是：

- 仅“关注”单一动作贡献了全部效果；
- 已经独立复核业务显著性；
- 该效果可以外推到其他平台或所有用户。

## 决策链路

```text
48%→41% 异常
→ 人群结构下钻
→ 设备结构形成方向性压力，分期占比缺失时不计算真实贡献
→ 核心路径转化率未同步下降形成反向证据
→ 标杆用户差异产生相关性假设
→ 随机实验评价完整引导策略
→ 在公开效果量缺失的边界内形成项目决策
```
