# A/B 实验决策指南

## 1. 明确目标策略和目的

老带新案例：

- 策略：简化邀请页面，将邀请按钮放在第一页明显位置；
- 目的：提升老用户邀请点击率，最终服务拉新用户数。

## 2. 确定核心指标、最终指标和护栏

| 类型 | 老带新案例 |
|---|---|
| 核心机制指标 | 邀请点击率 |
| 最终业务指标 | 拉新用户数 |
| 价值护栏 | 首月价值/激励成本倍数 |
| 相关指标 | 裂变率、人均邀请人数、新用户访问频次与回访 |

选择邀请点击率作为核心指标，是因为页面改版直接作用于该动作；这不意味着拉新用户数不重要。

## 3. 预注册最小样本和周期

老带新参数：

- 历史基线：17%；
- MDE：绝对提升 3 个百分点；
- 双侧显著性水平：`α=0.05`；
- 统计功效：80%；
- 分流比例：1:1。

最低样本量由两比例检验公式计算。实际周期还要满足：

1. 覆盖最低样本量；
2. 走完完整业务周；
3. 覆盖曝光—点击—邀请—分享链路；
4. 降低新奇效应影响。

不应在样本量刚达到最低值时自动停止。

## 4. 稳定 Hash 分流

对唯一用户 ID 进行稳定 Hash 后取模。例如使用 100 个桶：

- 0—49：实验组；
- 50—99：对照组。

同一用户在实验周期内保持分组稳定。对于可能存在网络效应的场景，需要评估是否按城市、人群或关系簇进行更高层级分流。

## 5. A/A 与分流可信度

A/A 阶段检查：

- 核心指标是否出现不应有的显著差异；
- 样本比例是否符合预设，即 SRM；
- 渠道、设备、城市等关键维度是否均衡；
- 埋点、曝光和指标口径是否一致；
- 用户是否发生跨组污染。

如果检查失败，应先修复分流或数据链路。无法随机分流时，可评估 DID、PSM 等观察性方法，但其识别假设和证据等级不能与随机实验等同。

## 6. 实验运行

- 实验组：新版简化邀请页面；
- 对照组：旧版页面；
- 周期：两周；
- 总样本：约 700 万；
- 核心指标：邀请点击率。

运行中只监控样本进度、数据质量、污染和严重护栏风险。最终结论在达到预设周期和样本后统一判断，避免频繁窥视 P 值扩大一类错误。

需要关注：

- 新奇效应；
- 网络干扰；
- 同时上线的其他策略；
- 节假日和业务周；
- 指标延迟成熟。

## 7. 实验后判断

老带新结果：

```text
对照组 17.0%
实验组 23.5%
绝对提升 +6.5pp
相对提升约 +38.2%
p<0.05
```

决策需要综合评估三类条件：

### 数据可信条件

- A/A、SRM、分层均衡和埋点没有阻断问题；
- 分流单位、曝光口径和分析样本一致。

### 效果条件

- 统计显著；
- 效果方向正确；
- 达到预设 MDE 或具备足够业务价值；
- 置信区间能够排除不可接受结果。

### 业务护栏条件

- 用户质量、体验和价值指标没有不可接受恶化；
- 成本口径可比；
- 推广后的边际效果仍值得监控。

`p<0.05` 只满足统计推断的一部分要求，不自动等同于上线决策。

## 8. 结论强度

实验评价的是实验组与对照组之间的完整处理差异。如果页面同时调整信息量、层级和按钮位置，只能说“完整页面简化方案有效”，不能把全部效果归因于某一个组件。

新用户留存案例只披露了“两周、约 30 万总样本、`p<0.05`”，未披露实验组和对照组绝对留存率，因此本项目不复算绝对提升、相对提升、置信区间或业务显著性。
