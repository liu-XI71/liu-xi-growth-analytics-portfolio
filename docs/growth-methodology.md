# 用户增长分析决策方法

## 一条主线

```text
业务目标
→ 指标合同
→ 异常确认
→ 贡献拆解
→ 负证据
→ 可证伪假设
→ 随机实验
→ 业务与价值护栏
→ 决策和持续监控
```

## 1. 从业务目标反推指标

首先明确目标业务结果，再选择与策略作用路径最接近的机制指标。

老带新：

- 最终结果：拉新用户数；
- 页面机制：邀请点击率；
- 链路诊断：分享成功率；
- 决策护栏：新用户质量和首月价值/激励成本倍数。

新用户留存：

- 最终结果：次 7 日内留存率；
- 结构诊断：渠道、设备和画像；
- 路径诊断：从注册到互动的环节转化；
- 候选机制：主页与关注行为；
- 因果验证：退出页引导策略实验。

## 2. 异常确认先于根因分析

确认：

- 指标口径是否变更；
- 数据是否延迟、重复或缺失；
- 人群、窗口和版本是否一致；
- 变化是否超过正常波动；
- 是否与业务事件同期发生。

数据质量失败时只报告异常，不给出根因。

## 3. 结构贡献不能只讲方向

“某人群表现更差且占比增加”只说明方向，需要通过 mix-shift 分解量化贡献。无法获得占比变化时，结论必须停在“可能形成结构压力”，不能继续声称解释了全部变化。

## 4. 负证据用于收窄问题

负证据不是“没有发现”，而是主动降低某个假设的优先级：

- 邀请点击下降、分享成功率保持高位：优先检查分享之前；
- 留存下降、核心路径转化率未同步下降：降低普遍路径阻塞的调查优先级。

负证据从不等于彻底证明问题不存在。

## 5. 标杆用户只负责生成假设

高频高时用户与低活跃用户的行为差异可能同时受到：

- 原始意愿；
- 使用机会；
- 内容偏好；
- 渠道来源；
- 设备和城市；
- 反向因果。

因此标杆分析筛选候选机制，随机实验才评价产品策略。

## 6. 实验用于识别策略效果并支持决策

完整实验包含：

- 目标、核心指标和护栏；
- 基线、MDE、Alpha 和 Power；
- 样本量、业务周期和分流单位；
- A/A、SRM、均衡与污染；
- 效果量、置信区间和分层结果；
- 统计显著性、业务显著性和护栏状态三类决策条件。

## 7. 显著后仍需价值判断

即使策略改善核心指标，也要判断：

- 下游是否转化为最终业务结果；
- 新用户质量是否可接受；
- 成本和价值是否采用相同归因范围；
- 平均回报是否掩盖边际回报下降；
- 推广人群是否与实验人群一致。

## 8. 决策必须保留边界

决策备忘录至少包含：

- 事实；
- 解释；
- 负证据；
- 未解决问题；
- 假设；
- 实验结果；
- 护栏；
- 行动；
- 风险；
- 后续监控。

高质量分析要求结论强度与证据等级一致。
