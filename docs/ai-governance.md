# 智能分析与证据治理

## 设计目标

刘希｜增长与实验采用“确定性计算—证据组织—结论治理”的分层机制。系统先形成指标、统计结果和证据包，再允许智能解释在既定边界内组织文字。

> 先计算，再解释；先形成证据，再生成文字。

## 三类职责

### 确定性程序已经实现

- 指标分子、分母、观察窗口和统计粒度合同；
- 趋势、标准化漏斗、留存和价值/激励成本倍数计算；
- 在输入完整时计算结构贡献；输入不足时返回缺失字段，不用估计值补齐；
- 在使用者录入组内人数与成功人数后，计算样本量、效果量、置信区间、Z 检验、P 值和 SRM；
- 前后端共用 SHA-256 分流合同与黄金向量；
- 数据质量、声明—证据一致性、叙事数字和高风险语义检查。

### 可编辑检查清单

A/A、埋点一致性和渠道/城市/设备分层均衡属于实验 SOP。当前项目复盘没有披露这些检查的真实结果，因此页面默认显示“未录入”。使用者可以在试算场景中标记状态，但该状态不会被写回项目事实。

### 叙事层可以负责

- 组织现有聚合证据；
- 解释负证据和未决问题；
- 将相关性线索表达为待验证假设；
- 形成周报和行动建议草案；
- 指出还需要补充什么数据。

叙事层不能计算或修改统计结果。

## 声明—证据合同

每条正式声明归入以下类型：

| 类型 | 定义 | 最低证据要求 |
|---|---|---|
| `fact` | 可由已知事实或程序结果直接复核 | 至少一个有效证据编号 |
| `interpretation` | 对多个事实的业务解释 | 支持证据、结论边界与反向证据 |
| `hypothesis` | 尚待验证的机制猜想 | 证据线索与验证方式 |
| `causal_result` | 随机实验支持的策略效果 | 随机实验与已披露结果 |
| `action` | 基于证据的建议 | 决策门、风险与人工确认 |

确定性声明验证器检查证据 ID、声明类型和最低证据等级。缺少留存实验绝对值时，只允许报告“方向提升且 `p<0.05`”，不允许补写组率或百分点。

## 本地模型的双重门禁

### 数字白名单

本地模型输出的数字必须已出现在聚合证据包中；新增无依据数字会触发回退。

### 高风险语义规则

以下内容会触发回退：

- 把标杆差异等相关性写成因果；
- 把“次7日内留存率”误写为精确 D7；
- 把首月价值/激励成本倍数写成完整 ROI、LTV、CAC、利润或净收益；
- 在分期设备占比缺失时声称已算出结构贡献、残差或完全解释下滑；
- 把负证据写成“彻底排除”“证明没有问题”等绝对结论。

这是面向本项目高风险表达的规则集，不宣称已经完成通用的逐句事实核查或逐句引用验证。

## 运行模式

### Deterministic Evidence

默认模式。固定模板读取确定性证据，输出稳定、可复现，不需要模型或密钥，适合 GitHub Pages 与自动测试。

### Local Ollama

可选模式。模型只接收聚合证据包，不接收行级演示数据。需要显式设置：

```text
LXGA_COPILOT_NARRATIVE_MODE=ollama
LXGA_OLLAMA_BASE_URL=http://127.0.0.1:11434
LXGA_OLLAMA_MODEL=本机模型名
```

服务未配置、超时、返回格式错误、数字越界或语义越界时，系统自动使用确定性文字并记录回退原因。

## 结论约束规则

系统针对以下高风险表达执行规则校验：

- 百分比与百分点；
- 次7日内留存与精确第7日留存；
- 相关性与因果性；
- 统计显著与业务显著；
- 结构贡献与输入缺口；
- 首月价值成本口径与完整 ROI；
- 项目事实、派生计算与模拟数据；
- 负证据能够支持和不能支持的结论。

该规则集仅覆盖本项目定义的高风险表达，不外推为通用事实核验能力。规则触发时，系统保留确定性证据并回退至受控文本。
